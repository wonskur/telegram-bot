# Telegram-боты на aiogram 3 и asyncio
Репозиторий содержит двух независимых Telegram-ботов, демонстрирующих работу с асинхронным фреймворком `aiogram` и интеграцию сторонних API
* **AI_bot.py** - бот со встроенным искусственным интеллектом (Gemini API).
* **Subscribe.py** - бот с системой имитации оплаты и проверки уровня подписки.
---
## 🛠️ Установка и настройка
### 1. Клонирование и подготовка окружения
Запустите терминал и выполните следующие команды:
```bash
# Создаем виртуальное окружение
python3 -m venv venv
# Активируем его
source venv/bin/activate
# Обновляем pip и устанавливаем зависимости
pip install --upgrade pip
pip install -r requirements.txt
```
